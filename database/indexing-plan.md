# Indexing plan

| Index | Columns | Query supported |
| --- | --- | --- |
| `doc_workspace_time_idx` | `workspace_id, updated_at DESC` | Recent documents in one workspace |
| `doc_owner_time_idx` | `owner_id, updated_at DESC` | Recent documents owned by one user |
| `revision_doc_version_idx` | `document_id, version DESC` | Latest revisions for one document |
| `comment_doc_state_idx` | `document_id, is_resolved, created_at DESC` | Unresolved comments for one document |
| `audit_workspace_time_idx` | `workspace_id, created_at DESC` | Recent workspace activity |
| `audit_entity_idx` | `entity_type, entity_id` | Audit history for one entity |

Primary keys and unique constraints create their own indexes. Foreign-key
indexes generated by Django support relationship lookups. Validate the plan
with realistic data using `EXPLAIN (ANALYZE, BUFFERS)`.
